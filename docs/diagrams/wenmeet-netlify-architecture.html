Every place this app touches Netlify

From git push to a served page. WenMeet's own code — the scheduling engine, Clerk auth, the Next.js app — lives outside this map; what's shown here is only the surface where that code meets Netlify's platform.

Netlify platform

Everything in this box is provisioned and run by Netlify — configured once in netlify.toml and Netlify's own dashboard, not in app code.

Build & runtime

@netlify/plugin-nextjs builds the app and translates every Next.js API route into a Netlify Function — stateless, cold-starting on demand.

netlify.toml → [build] command, publish = ".next"

Hosting & domain

Site wenmeet-demo serves the built app over Netlify's CDN, with wenmeet.conscience.fund as a Netlify-managed custom domain — DNS and TLS both handled by Netlify.

Context & config

Per-environment values live in netlify.toml contexts, plus Clerk / Google / Microsoft secrets set directly in Netlify's env var UI — never committed.

[context.production.environment] DATA_STORE = "netlify" [context.deploy-preview.environment] DATA_STORE = "netlify"

Netlify Database

Managed Postgres, queried through @netlify/database's raw SQL client — no ORM. NETLIFY_DB_URL is injected automatically; nothing to configure by hand.

netlify/database/migrations/20260818200113_initial_schema.sql

Deploy previews

Every branch/PR gets its own preview URL and its own isolated database branch, seeded from production — real persistence, safe to test against, torn down when the branch closes.

Functions → outside calls

Deployed API routes are what actually reach out to Clerk and the calendar providers below — Netlify runs the function, the destination isn't Netlify.

Plain local dev

next dev with no Netlify CLI falls back to DATA_STORE=memory — an in-process store, no database reachable, nothing persists across a restart.

Docker image

A standalone multi-stage build that runs on any container host. Independent of Netlify's build pipeline by design — must stay on DATA_STORE=memory, since Netlify Database isn't reachable outside Netlify's own runtime.
